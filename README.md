# Allergoproba — демонстрационный HTML-макет

Статический frontend с отдельными HTML, CSS и JavaScript, без сборки и backend.

## Запуск
Откройте `index.html` в браузере. Для работы с локальным сервером: `python -m http.server 8000`.

## Доступные экраны
- Новая заявка
- Навигационное меню
- Личный кабинет: история входов, смена пароля, цена за забор крови
- Сопроводительный лист: город, адрес, тарифы, виды анализов, дата и предварительный просмотр
- Реестр заявок: поля поиска, источники, статусы и демонстрационные действия

## Структура
- `index.html` — разметка
- `assets/css/styles.css` — основные стили
- `assets/css/extra-pages.css` — стили новых экранов
- `assets/js/app.js` — основная навигация и формы
- `assets/js/extra-pages.js` — сопроводительный лист и реестр заявок

Реальные персональные данные и медицинские заявки не загружаются. Действия, которым нужен backend, показывают явное демо-сообщение.

Исправлена пустая область высотой в один экран перед разделами «Реестр заявок» и «Сопроводительный лист»: контейнер `.screen` больше не резервирует высоту для скрытых разделов. Переключение страниц прокручивает к началу. Добавлена безопасная обработка ограничений localStorage.

## Локализация
В личном кабинете добавлена вкладка «Язык интерфейса»: русский / қазақша. Полный перевод видимых подписей, меню, форм, фильтров, подсказок и демо-сообщений в `assets/js/i18n.js`. Выбор хранится в localStorage. Без внешних зависимостей.


## Иностранный гражданин (19.10.2026)

В разделе **«Новая заявка»** отметьте «Иностранный гражданин, ИИН отсутствует».
При включении ИИН очищается и блокируется; появляются поля:

- Тип документа: паспорт, вид на жительство, удостоверение лица без гражданства, удостоверение беженца, свидетельство о рождении, другой документ.
- Номер документа (не обрезаются ведущие нули).

При нажатии «СОХРАНИТЬ» проверяется заполнение типа и номера документа для иностранного гражданина, затем отображается **демо-сообщение**, без сохранения заявки на сервер. При отключении галочки иностранные поля сбрасываются, а ИИН снова доступен; кнопка общего сброса учитывает эту логику. «Заполнить из согласия» неактивна: для неё нужна реальная интеграция с согласиями.

**Локализация:** интерфейс регистрации иностранца, список документов, подсказки и ошибки переведены на казахский в `assets/js/i18n.js`. Переключать язык: **Личный кабинет → Язык интерфейса**. Подключение к интернету не нужно.
